TV URLs

—
Each output is its own page. Open the URL on that TV once and leave it — the frame is derived from the wall clock, not from a start message, so every device lands on the same frame with no server, no socket and no sync handshake.
URL form works anywhere
epoch—
this device now—
loop position—
Per-device nudge: &skew=±ms · diagnostics on a TV: press i. Devices only need their own clocks to agree — NTP gets you inside ~100 ms, which is under one chant beat.
To reach real TVs and phones, serve the folder over HTTP — python -m http.server 8000 — and swap file:///… for http://<this-machine>:8000/. A file:// URL only opens on this machine.

URL parameters

reference
tv
1-based output index. Omit for the control room.
event
event type, e.g. td, pick6, chant
team
school, e.g. TEX. The two are independent.
opp
opponent. Defaults to the school's rival.
layout
layout id, e.g. row4
gap
bezel gap in screen widths. 0 = pixel to pixel. Must match on every output in a wall.
t0
epoch override in ms. Same value everywhere = same phase.
rest
ms of lockup between loops. Default 2500.
skew
per-device offset in ms, + runs ahead.
bezel
0 to drop the letterbox guides.
diag
1 to show the clock overlay.
